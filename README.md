# Fimken

A fresh rebuild of Fimken, a website for visualising music.

## Project status

Repository initialised. The new application is yet to be built.

## Direction

- Create music-reactive visuals in the browser.
- Develop and preview the rebuild before replacing the current website.
- Deploy to Vercel and connect fimken.com when the rebuild is ready.

## Deployment

The existing fimken.com deployment is separate from this repository. Creating
this repository does not change the live site or its domain configuration.
